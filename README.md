# Arabic Transcriber

A minimal local desktop application for transcribing Arabic audio and video with Cohere Transcribe Arabic. Planned for macOS and Windows, with file import, YouTube audio import, progressive transcript display, optional approximate segment timestamps, and TXT, DOCX and PDF export.

## Development status

This repository currently contains the project specification and implementation handoff. Application implementation, testing, packaging, and CI are the next task. Startup commands will be added after they have been implemented and verified.

See [the project specification](docs/PROJECT.md). Local implementation tickets and handoff notes live in the Git-ignored `.scratch/arabic-transcriber/` directory.
